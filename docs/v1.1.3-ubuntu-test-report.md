## Commits

| Commit | What was wrong |
|---|---|
| `5e46704` | No server package could be built on Linux: node-pty's macOS/Windows prebuilds went into it and failed the package's own ELF check. 1.1.2 (`ab4f76d`) has the same bug. |
| `cc8249b` | The package's offline scan failed on comment links in node-pty and ws, and on CMM's homepage URL; none is fetched. |
| `ca24b7c` | e2e: real LibreOffice converts the plain-text "broken" `.doc`; only the stand-in refused it. |
| `c7634e4` | Events sent while a tab's event stream was reopening were lost, and it reopens on every folder watch change: a finished move left folders busy until a reload. Jobs are now refetched on each open. |
| `d81c179` | Terminals run as `cmm`, whose home has no `.profile`, so `~/.local/bin` (Claude Code's install folder) wasn't on `PATH`. |
| `4163d39` | Settings › Terminals and the guide say how to install Claude Code for `cmm`. |
| `dce17a5` | node-pty's helper paths made Next trace the whole project: `vendor/node`'s 31 MB tarball was in every package (72 → 102 MB). |
| (this release) | `deploy/linux/cmm-server-setup.sh`: one script for CMM behind nginx on a tailnet; the server guide's *Option D*. |

## Works as designed, but worth changing (not fixed)

- `CMM_SOFFICE_PATH` is only a first place to look; CMM then searches `PATH` and the usual folders, so pointing it at
  a missing file doesn't turn previews off. Either the handover tip or the behaviour should change.
- The account menu's theme switch: "System" runs past the control's edge (both themes).
- After **Replace**, an open file also shows "Updated from disk" next to "Replaced …", though CMM made the change.
- `cmm gen-cert` on a server behind a proxy breaks it (502); the guide now warns, but the command could refuse when
  `trustedProxies` is set.
- The e2e suite expects `CMM_SOFFICE_PATH=e2e/support/fake-soffice.sh` from the shell; nothing in the config sets it.

## Ready to release on servers?

Yes, with the commits above. Without `5e46704` and `cc8249b` no Linux package can be built at all.
