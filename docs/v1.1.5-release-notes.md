**CMM — Context Memory Manager 1.1.5**: a self-hosted, offline file manager for the memory folders and prompts of your AI tools. [Website](https://joshwamiasco.github.io/context-memory-manager/) · [Desktop Guide](https://github.com/JoshWAMiasco/context-memory-manager/blob/main/docs/guides/desktop-guide.md) · [Server Guide](https://github.com/JoshWAMiasco/context-memory-manager/blob/main/docs/guides/server-guide.md)

This release also brings 1.1.4 (CMM on your phone), which had no release of its own.

## What's new in 1.1.5: Jobs

- **Jobs**: leave an agent working while you're away. **Run as a job** on a terminal's title bar (or the docked column) turns it into a job, which keeps running in the background, like a `tmux` session, after CMM is closed, restarted, updated or crashes. Ordinary terminals still end with CMM.
- **The Jobs page** shows a card for each job: when it started, how long it has run and in which folder. Open one to see its terminal across the whole window, with **Open in editor**, **Make a terminal** (back to an ordinary terminal) and **Discard**, which ends the job and leaves no trace. Jobs also show as cards on the dashboard and in the navigation.
- **Updating keeps your jobs**: jobs started under an older version keep running after an upgrade, and CMM finds them again when it starts. Rebooting the machine, or uninstalling CMM, ends them.
- **Server**: `cmm.service` now stops only CMM itself (`KillMode=process`), so `systemctl restart cmm` and upgrades leave jobs running. Terminals get `TMPDIR=/var/lib/cmm/tmp`, because the service's private `/tmp` is deleted when it stops.

## What's new in 1.1.4: CMM on your phone

- **Phone layout**: a bottom bar (Drives, Search, Backup, Trash, Menu) and a menu drawer with your account, theme, pages, full screen, Lock now, Sign out and the version. The explorer shows the files, the open file or the terminal one at a time, from a switch at the top.
- **Terminals on touch screens**: a key bar with Esc, Tab, Ctrl, ^C, arrows and Enter, so menus like Claude Code's can be driven from a phone. The on-screen keyboard types cleanly (Android autocorrect no longer arrives garbled), the page shrinks above it, and a vertical swipe scrolls.
- The Markdown toolbar fits a phone in one scrolling row, and uploading several files asks for the password once.
- **Server**: `cmm add-storage` also gives the folder's owner access to the files CMM creates, so they stay open to them in their own shell. `cmm-server-setup.sh` takes `--https-port` (for when another site already has 443) and `--port`, and its closing summary no longer turns on HTTPS in CMM by mistake (which made nginx answer 502).

## Download

| File | For |
|---|---|
| `cmm-server-1.1.5-linux-x64.tar.gz` (+ `.sha256`) | Ubuntu server (x64): the offline server package with its own Node.js runtime and `install.sh` |
| `cmm-server-setup.sh` | Optional: installs that package behind nginx on a Tailscale network in one step |

**Install on Ubuntu:** put the three files in one folder on the server, then either

```bash
# on your tailnet, with HTTPS (turn on MagicDNS and HTTPS Certificates in the Tailscale admin console first)
sudo ./cmm-server-setup.sh --package ./cmm-server-1.1.5-linux-x64.tar.gz

# or the plain install, as before
tar -xzf cmm-server-1.1.5-linux-x64.tar.gz && cd cmm-server-1.1.5-linux-x64 && sudo ./install.sh
```

Upgrading keeps your data, users and settings; `sudo cmm rollback` returns to the previous version. For arm64, build the package from source (`npm run package:server -- --arch arm64` on an arm64 machine, see the README).

**Desktop apps** (macOS, Windows, desktop Linux): 1.1.5 builds aren't attached yet. Until they are, use the [1.1.0 downloads](https://github.com/JoshWAMiasco/context-memory-manager/releases/tag/v1.1.0).
